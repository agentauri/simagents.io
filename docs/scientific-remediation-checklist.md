# Scientific Remediation Checklist

This checklist tracks what is still needed before SimAgents results should be described as strong evidence.

## P0

- Lock a browser experiment definition format with seed, roster, prompt, and runtime config.
- Add focused engine tests for experiment summaries and export shape.
- Add browser smoke coverage for experiment run/export.
- Define which metrics are mechanistic, heuristic, or inferential.
- Require claim-review notes before publishing results.

## P1

- Add replicated browser experiment workflows.
- Add deterministic baseline presets.
- Add artifact hash reporting for exported bundles.
- Add normality and effect-size guidance for comparative claims.

## P2

- Improve replay inspection for long runs.
- Add first-class bundle creation UI.
- Add template-driven preregistration notes.
- Add automated warnings when users attempt to label exploratory runs as validated.
